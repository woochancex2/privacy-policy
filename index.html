패스루프 개인정보 처리방침

시행일: 게시일 기준 (최종 수정: 2026년 9월 12일)

패스루프는 개인정보를 수집하지 않습니다.

회원가입도, 로그인도, 분석·광고 추적도 없습니다. 학습 데이터는 전부 사용자의 기기 안에만 저장되며, 외부 서버로 전송되지 않습니다.

1. 수집·이용하는 정보

패스루프(이하 "앱")는 개인정보를 수집·이용하지 않습니다.

앱이 기기에 저장하는 학습 데이터는 다음과 같으며, 이것은 기기 내부에만 존재하고 외부로 전송되지 않습니다.

  • 카드·문제 은행 학습 기록(평가 결과, 복습 일정 — 간격 반복 학습 계산용)
  • 시험명·시험일(학습 계획 계산용)
  • 캐릭터 색 등 화면 표시 설정

2. 저장 방식과 보관 기간

  • 학습 데이터는 기기 내부의 앱 전용 저장소(Application Support)에 JSON 파일로 저장됩니다.
  • 별도의 서버·클라우드 보관소가 없으므로, 앱을 삭제하면 학습 데이터는 즉시 소멸합니다.

3. 데이터 삭제 방법

  • 전체 삭제: iOS 홈 화면에서 앱을 삭제하면 저장된 모든 학습 데이터가 함께 삭제됩니다.
  • 개별 삭제: 앱 내에서 덱(문제 목록)을 삭제하면 해당 덱의 카드와 학습 상태가 함께 제거됩니다.

4. 제3자 제공·위탁

개인정보의 제3자 제공·처리 위탁은 없습니다.

5. 알림

앱은 복습 리마인더를 위해 기기 로컬 알림만 사용합니다(원격 푸시 아님). 알림 권한을 거부해도 학습 이용에는 지장이 없으며, 앱 안에서 학습 일정을 언제든 확인할 수 있습니다.

앱은 계정 가입·개인정보 수집이 없으므로 만 14세 미만 이용자에 대한 별도 확인 절차가 없습니다. 누구나 안전하게 이용할 수 있도록 정보 수집 자체를 하지 않습니다.
