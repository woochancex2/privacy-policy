패스루프 개인정보 처리방침

시행일: 게시일 기준 (최종 수정: 2026년 9월 27일)

패스루프는 계정·앱 서버·앱 내 AI 서비스를 운영하지 않습니다.

학습자료와 기록은 앱의 기기 저장소에 보관됩니다. 사용자가 프롬프트나 내용을 복사해 다른 앱에 직접 붙여넣으면, 그 앱·서비스의 개인정보 처리방침이 적용됩니다.

1. 수집·이용하는 정보

패스루프(이하 "앱")는 계정을 만들거나 앱 서버로 학습 데이터를 전송하는 기능을 제공하지 않습니다. 앱은 다음 내용을 사용자의 기기 내 앱 저장소에 저장합니다.

  • 사용자가 만든 카테고리·덱·문항, 가져오기 원문·초안, 직접 첨부한 이미지
  • 학습 평가·복습 일정·세션 기록·학습 시간·메모와 저장한 학습 범위
  • 시험명·시험일, 알림 설정, 캐릭터 진행·코인·꾸미기 상태, 화면 표시 설정

앱은 광고 추적이나 분석 SDK를 사용하지 않습니다. 사진·파일은 사용자가 시스템 선택기에서 선택한 경우에만 가져옵니다. 로컬 알림은 기기에서 예약하며 원격 푸시 서버를 사용하지 않습니다.

2. 저장 방식과 보관 기간

  • 덱·문항·학습 상태 등은 앱 전용 저장소(Application Support)에 저장됩니다. 첨부 이미지는 앱 전용 파일로 저장됩니다.
  • iOS 기기 백업 설정에 따라 앱 전용 저장소의 데이터가 기기 또는 iCloud 백업에 포함될 수 있습니다. 백업의 보관·복원은 Apple의 설정과 정책을 따릅니다.
  • 앱 자체는 학습 데이터를 위한 별도 서버 보관 기간을 설정하지 않습니다.

3. 데이터 삭제 방법

  • 개별 삭제: 앱 내에서 덱·문항·메모 등 제공되는 삭제 기능을 이용할 수 있습니다.
  • 앱 저장소 삭제: 앱을 삭제하면 기기의 앱 저장소가 제거됩니다. 단, 이전 기기 백업이나 다른 AI 서비스·클립보드에 복사된 내용은 별도로 남을 수 있습니다.
  • 백업본은 해당 기기·Apple 계정의 백업 관리에서, 외부 AI에 제공한 내용은 해당 서비스에서 별도로 삭제해야 합니다.

4. 제3자 제공·위탁

앱은 학습자료를 외부 AI로 자동 전송하지 않습니다. AI 문제 만들기는 프롬프트를 복사해 사용자가 선택한 AI 서비스에 직접 붙여넣는 방식입니다. 프롬프트에 사용자가 포함한 내용과 그 서비스에 첨부한 파일은 해당 AI 제공자의 이용·개인정보 처리 조건에 따라 처리될 수 있습니다. 민감하거나 공유 권한이 없는 자료는 전송하지 마세요.

사용자가 프롬프트 복사 기능을 사용하면 해당 텍스트가 iOS 시스템 클립보드에 기록됩니다. 클립보드 접근·동기화 동작은 iOS 설정과 기능을 따릅니다.

5. 알림

앱은 복습 리마인더를 위해 기기 로컬 알림만 사용합니다(원격 푸시 아님). 알림 권한을 거부해도 학습 이용에는 지장이 없으며, 앱 안에서 학습 일정을 언제든 확인할 수 있습니다.

6. 학습 콘텐츠 출처 고지

시험·외국어 학습자료의 출처와 이용 조건은 앱 내 각 자료의 ‘출처·이용 안내’에서 확인할 수 있습니다. 자료별 고지는 해당 출처와 적용 조건을 따릅니다.

7. 만 14세 미만 이용자

앱은 이용자의 나이를 별도로 확인하지 않습니다. 사용자가 앱에 입력하거나 첨부하는 내용에 개인정보가 포함될 수 있고, 사용자가 내용을 외부 AI 서비스에 직접 제공하면 해당 서비스의 처리 조건이 적용됩니다. 미성년자는 개인정보나 민감한 자료를 입력·공유하기 전에 보호자와 확인해 주세요.
